# 功能路线

## 0.1.0 已提供

- CLI/TUI 共用目录发现、默认配置、参数校验及插件执行。
- Excel 默认 table，支持 SFX 预设和自定义工作表、表头、字段及默认值。
- WAV/FLAC/OGG/MP3 互转与本地 FFmpeg 检测。
- PNG/JPG/JPEG 等比缩放、倍数居中裁切、透明与 EXIF 处理、预览计划。
- 输出跟随输入根目录并避重，递归保留结构、排除历史输出，支持指定目录跳过/覆盖。
- 共享转换生命周期、最终名称保护、逐文件结果、进度和取消。
- TUI 展开选项列表、规则说明、参数草稿、覆盖确认、依赖重新检测与停止。
- tsdown 构建项目代码、标准 npm TGZ、外置运行依赖和隔离安装验收。

## 后续按实际需求扩展

- 文件路径选择、打开输出目录及任务记录。
- 图片自由选区裁切、比例预设和前后对比。
- 大工作簿与图片后台处理，提升长任务取消响应。
- Unity 项目扫描和资源检查，以真实项目定义规则。
- 项目模板、构建与上传工具，先确定输入输出及凭据边界。

新增工具遵循 [插件开发](plugins.md)。Web 工作台独立维护在 codex/feat-web。
